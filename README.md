# RDM Telegram Bot

Простой Telegram-бот для Redmine/RDM, который помогает заносить трудозатраты.

## Возможности

- выбор проекта;
- избранные проекты для быстрого доступа;
- выбор задачи проекта;
- последняя выбранная или использованная задача поднимается вверх в списке задач проекта;
- ввод номера задачи на этапе выбора задачи;
- последние задачи пользователя после успешной отправки трудозатраты;
- личный вход каждого сотрудника по Redmine API key;
- выбор часов: 30 минут, 1, 1.5, 2, 2.5 или 3;
- ручной ввод времени, например `45 мин`, `1,25`, `1:30` или `2ч 30м`;
- быстрый переход к задаче по номеру, например `7875` или `#7875`;
- выбор даты, по умолчанию сегодня;
- деятельность `Support` выбирается по умолчанию, при необходимости можно выбрать другую;
- ввод комментария;
- отправка трудозатраты в Redmine через API.

## Настройка

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните `.env`:

```env
BOT_TOKEN=telegram_bot_token
RDM_BASE_URL=https://rdm.example.com
```

`RDM_API_KEY` больше не нужен для работы бота: каждый сотрудник вводит свой ключ в Telegram через `/login`. Ключи сохраняются локально в `bot.db`, этот файл игнорируется git.

## Команды

- `/login` - войти в свой Redmine-аккаунт по API key.
- `/logout` - выйти и удалить сохраненный API key.
- `/me` - проверить, под каким Redmine-пользователем выполнен вход.
- `/project` - начать выбор проекта.
- `/favorites` - открыть избранные проекты.
- `/setup_favorites` - открыть все проекты и настроить избранные тумблером.
- `/recent` - открыть последние задачи.
- `/cancel` - отменить текущий сценарий.

До входа в нижнем меню показывается только кнопка `🔐 Войти`. После входа она пропадает, и в меню появляются `📂 Выбрать проект`, `⭐ Избранные проекты`, `🎫 Последние задачи` и `⚙️ Настроить избранное`. Выход выполняется только командой `/logout`.

Избранное настраивается в разделе `⚙️ Настроить избранное`: нажмите на проект один раз, чтобы добавить его в избранное, и еще раз, чтобы убрать. Последние задачи сохраняются автоматически после успешной отправки трудозатраты в Redmine.

После первого входа бот сразу предлагает отметить избранные проекты. При обычном выборе проекта избранные показываются сверху, а ниже остается общий список всех проектов.

Списки проектов выводятся сеткой по 3 кнопки в ряд и продолжают поддерживать перелистывание.

## Описание профиля бота

Тексты для стартового сообщения и профиля Telegram-бота лежат в `constants.py`.

Чтобы записать описание в профиль бота Telegram, заполните `BOT_TOKEN` в `.env` и выполните:

```powershell
.\.venv\Scripts\python.exe setup_bot_profile.py
```

## Запуск

```powershell
.\.venv\Scripts\python.exe bot.py
```

Или:

```powershell
.\run_bot.ps1
```

## Структура

- `bot.py` - точка запуска.
- `handlers.py` - сценарий Telegram-бота.
- `keyboards.py` - кнопки и клавиатуры.
- `formatters.py` - форматирование текста сообщений.
- `parsers.py` - разбор номера задачи и ручного ввода времени.
- `config.py` - чтение настроек из `.env`.
- `rdm_client.py` - клиент Redmine API.
- `setup_bot_profile.py` - обновление описания в профиле Telegram-бота.
- `user_store.py` - локальное хранение API key сотрудников в SQLite.
